# Copilot skills

Skills for the Copilot coding agent, not for Actions: a repo puts them in `.github/skills/` (PLAN.md section 3). Until `scaffold-sync` (Phase 3) opens that PR, a repo admin copies this folder's skill folders there by hand; `.github/**` is a protected path, so it's a human's PR.

- `tdd`: tests and scenarios first, for each PR.
- `implement`: how a SCAFFOLD issue becomes PRs that pass the gates.
